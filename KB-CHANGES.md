# GridPane KB change history

Every monitored change to the GridPane Knowledge Base, newest first,
grouped by year and month. One entry per reporting interval; a body
"change" means the rendered article hash moved, which can be markup
only — read the article before editing a citation.

Generated by `scripts/gridpane-kb-history.sh` from the weekly report
ledger; edit the ledger or the script, never this file by hand.

- Ledger: `out/gridpane-kb-weekly/state/history.jsonl` (local, gitignored)
- Regenerate: `scripts/gridpane-kb-history.sh --backfill`
- Check: `scripts/gridpane-kb-history.sh --check`
- History begins at the earliest retained snapshot in the local cache.
